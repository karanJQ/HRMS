Access Control

5-Tier Role Architecture

Every user sees only what they need. Every action is logged permanently.

Super Admin
Full system control — manage users, configure workflows, view all departments, access audit logs and system settings.
HR Manager
HR operations — manage employees, process payroll, handle transfers, promotions, and approve APAR records across all departments.
Dept Head
Departmental view — review employee attendance, leave requests, initiate transfer nominations, fill APAR reports for subordinates.
HR Staff
Data entry & support — onboard employees, update service book, manage payroll inputs, handle grievance registration.
Employee
Self-service portal — view payslips, apply for leave, check attendance, view APAR results, raise grievances, access training records.
